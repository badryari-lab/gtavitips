## Where to go (needs Badr's own account)

1. **r/GTA6.** Read the sidebar rules on self-promotion before posting anything. Most subreddits expect you to take part in other threads first, and a new account that only drops links gets removed. Answering questions with a useful reply and one link where it fits works better than a post that is only an announcement.
2. **r/GTA, r/gaming.** Same rule. Only post when there is a real reason (a size or time that just became known).
3. **X and Discord GTA communities.** Reply with the fact and the link when someone asks the question the page answers.
4. **GTA fan wikis.** Adding a sourced fact with a citation to our page is allowed on some wikis and banned on others. Check each wiki's policy first.
5. **YouTube creators covering GTA 6.** A short email offering the unlock-time table or the rumor check, with no ask beyond "use it if useful". Only send it to people Badr actually follows.

Do not buy links or trade links. The 2026 report lists this as a penalty risk.
